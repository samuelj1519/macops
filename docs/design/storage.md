# 数据位置与保存边界

用 `mo dirs --roots` 查看命令实际使用的范围。以下默认路径以当前 HOME 为基准。

| 数据 | 默认位置 | 保存什么 |
| --- | --- | --- |
| 本机设置 | `~/.local/settings` | macops 读到的本机管理设置，受 `--settings` 选择 |
| 自有配置 | `~/.config/macops` | 软件目录、配置或来源配方、推荐设置等 |
| 持久数据 | `~/.local/share/macops` | macops 的持久数据根 |
| 状态 | `~/.local/state/macops` | 活动操作、历史、回执、迁移账本及部分隔离工作目录 |
| 缓存 | `~/.cache/macops` | 版本索引及其清理所需的归属信息 |
| 原生数据 | 相应的原生工具目录 | 已安装软件、插件和技能、Agent 设置、chezmoi 原生状态 |

显式参数可覆盖目录。默认目录受 XDG 设置及 HOME 影响。切换到独立 HOME 时，程序按范围处理环境覆盖。手动核对原操作时，应按原目录参数和原生作用域运行。 [上下文实现](../../crates/app/src/context.rs)

## 操作记录与可重建内容

活动记录保存原计划、作用域和执行阶段。历史用于查看已发生事项。存在同 ID 记录时，可读取的活动记录优先。活动记录损坏时，历史可供诊断，原操作的自动推进会暂停。回执和冻结证据可能仍用于收口，删除前先确定记录是否已完成。 [操作存储](../../crates/app/src/operations/store.rs) · [恢复流程](../flows/recovery.md)

索引按内容摘要保存。当前引用和创建所有权分别登记，内容相同可复用。清理只处理可证明由 macops 创建、当前符合条件并通过身份和摘要复验的对象。原生缓存由原生工具管理。 [清理实现](../../crates/app/src/catalog/cache.rs)

## 共享字段与凭据

同一配置字段可以有多个受支持的归属。同步只修改配方声明的字段。实时配置和静态管理源分别保留原值，最后一个归属释放后依据记录恢复。 [能力同步](../../crates/app/src/capability/capability_sync.rs)

推荐设置保存服务绑定和当前模型，密钥使用钥匙串条目 `org.macops.recommend.api-key`。推荐设置按系统用户独立加锁，软件升级记录不参与该设置事务。Agent 凭据元信息及实际认证按各自的客户端和凭据工具管理。 [推荐模型设置](../flows/recommend.md#推荐模型设置)
