# 业务流程

从要做的事选择一页。每页给出入口、代码和主要分支。共享的计划、确认、执行与恢复规则见「执行与恢复」。

| 业务 | 先读场景 | 重点边界 |
| --- | --- | --- |
| [推荐与安装](recommend.md) | 从公开仓库找到一个插件，选已有 Agent 配置安装 | 候选核验、模型边界、隔离安装与发布 |
| [技能和插件](capabilities.md) | 升级两个 Agent 的能力 | 多选、共享目录、幂等和未知结果 |
| [Agent](agents.md) | 登记已有配置、升级 CLI 或启动单独配置 | 可执行文件与配置、mise 漂移、原生结果 |
| [软件和服务](software.md) · [uv](uv.md) | 发现、接管、升级某一份安装 | 原生身份、索引与写入资格 |
| [配置](configuration.md) | 登记 chezmoi，查看差异并应用一个文件 | 原生解释、部分观察、源文件与目标文件 |
| [清单、迁移与清理](maintenance.md) | 搬迁旧数据，重放已核对声明或清理缓存 | 归属、旧记录兼容和数据保留 |
| [执行与恢复](recovery.md) | 原生工具退出后结果仍不明 | 原计划、实际进程、收口和续装 |

阅读时先记下 CLI 目标，用 [模块地图](../design/architecture.md#从入口定位代码) 找写入者，再沿流程找到测试。例子统一使用占位路径和合成配置。 [命令参考](../commands/README.md)
