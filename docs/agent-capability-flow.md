# 按 Agent 管理能力

## 操作协议

安装、升级、卸载、启用和停用共用目标选择。Agent 以用户启动它时使用的名称显示，同时显示配置目录。可重复传入 `--agent`，`--agent all` 选择该操作适用的 Agent。终端中省略目标时提供多选。没有终端的脚本应显式指定目标。既有配方和精确安装 ID 继续支持原有脚本。

脚本要写共享技能时，还需加 `--shared`。共享目录可能被名单外的客户端读取。旧的无 Agent 参数脚本仍走原有共享技能命令，迁移时请显式指定作用范围。

安装目标由来源的可用安装方式决定。升级、卸载及启停先查用户当前的实际安装，再沿用官方工具的维护方式。固定版本保留到用户选定另一版本。同名能力有多个不同来源时，先明确所选来源。项目安装继续保留项目作用域。

## 写入范围

1. 先核对 Agent、实际目录、当前安装、来源和所需版本，预览列出每个目标的操作。
2. 按实际写入位置合并同一份安装。共享目录必须核对其影响范围，范围不明确或超出选择时，暂停该项并说明怎样显式确认共享安装。
3. 确认后重新验证实际目录与原生登记。已达到目标的安装记为成功并跳过执行。
4. 每次写入后重新读取状态。确定失败可以继续处理互不共享的安装。结果未知时保留操作记录，先核对原结果再继续本批次。

Claude Code 和 Codex 新装复用已有插件安装器。已有插件在受支持的原生操作下维护。原市场指向固定的本地目录时，升级提示具体来源限制。换源涉及该目录关联的全部插件，只有能证明影响范围并明确确认时才执行。

## 配置登记

`mo agent add NAME --config PATH` 补充发现不到的 Agent。登记前验证命令、配置目录及客户端类型，并保存配置绑定。能力操作所需的来源或历史记录随操作生成。旧 `skill adopt` 调用作为隐藏的迁移入口保留，日常帮助与推荐流程提供安装、升级等目标明确的操作。chezmoi 的管理源登记沿用配置命令。

## 验收

验证一项已达目标加两项待更新的批次，重试只处理剩余项。验证共享安装只执行一次、未选择的消费者阻止写入、单个目标的未知结果阻止重复执行。使用隔离配置检查 Claude、Codex、Cursor 的支持范围与原生指令。验证 JSON、终端多选、无写入预演及旧入口。
